# DDB Platform Constitution

> **Authority document** — Governance truth. Do not edit without an approved governance task.

## Purpose

Defines the foundational laws of the DagjeDenBosch platform: one platform, three truths, canonical shell and page-family law.

## Three Truths

1. **OMDB truth** — Semantic meaning: what an experience is, who it is for, what it contains.
2. **Woo truth** — Final commerce truth: price, tax, order, payment.
3. **Booking truth** — Availability, participants, routing (direct / request / supplier confirmation).

## Shell Law

- Every public page renders inside the canonical DDB shell (header + main + footer).
- Admin pages render inside the WordPress admin shell.
- No page may override shell structure without a governance-approved exception.

## Page Family Law

See `DDB_PAGE_FAMILIES.md` for the six canonical page families and their laws.

## Change Control

Changes to this document require a governance task approved by the platform owner.
