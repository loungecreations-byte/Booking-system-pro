# DDB Core UI

Reusable design-system plugin for the platform.

## Provides
- Tokenized CSS foundation (`design-system.css`)
- Light and dark theme layers
- Reusable utility/component classes (`ui-*`)
- Minimal vanilla JS interactions and theme toggle support
- Shortcodes:
  - `[ddb_ui_section]`
  - `[ddb_ui_card]`
  - `[ddb_ui_btn]`
  - `[ddb_ui_grid]`

## Usage
Activate plugin and apply `ui-*` classes in Elementor containers/widgets to keep styling system-based and consistent.
