GENEREER EEN NIEUWE BSP MODULE (PARAMETRISCH)

PARAMS
- {{MODULE_NAME}} (PascalCase, bv: Notifications, Planner, Sales)
- {{SLUG}} (lowercase folder, bv: notifications)

OPDRACHT
- Maak map `/modules/{{SLUG}}/`
- File `/modules/{{SLUG}}/Module.php` met namespace `BSP\{{MODULE_NAME}}`
- Class `Module implements BSP\Core\ModuleInterface`
- `init(): void` aanwezig, met placeholder acties
- Update instructies voor `composer.json` psr-4:
  `"BSP\\{{MODULE_NAME}}\\": "modules/{{SLUG}}/"`
- Registreer module in `plugin.php` via:
  `$modules->register( \BSP\{{MODULE_NAME}}\Module::class );`

OUTPUT
- Toon file(s) volledig
- Toon patch snippet voor composer.json (alleen psr-4 blok)
- Toon voorbeeld diff voor plugin.php registratie
- Toon commando: `composer dump-autoload`
