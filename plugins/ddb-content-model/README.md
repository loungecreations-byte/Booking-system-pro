# DDB Content Model

Structured content schema plugin for city-platform entities.

## Post Types
- `spots`
- `activiteiten`
- `restaurants`
- `deals`
- `groepen`

## Taxonomies
- `categorie`
- `sfeer`
- `locatie`
- `type_activiteit`

## Custom Fields
- `ddb_hero_image`
- `ddb_intro`
- `ddb_highlights_json`
- `ddb_usp_blocks_json`
- `ddb_faq_json`
- `ddb_gallery_json`
- `ddb_cta_json`
- `ddb_reviews_json`

All fields are registered as post meta with REST support and editable in the provided admin meta box.
